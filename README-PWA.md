# Mutlu Akü Yönetici Portalı – Telefon kurulumu

## Android kurulumu
Chrome'da `https://kapgan1453.github.io/ADMIN/` adresini açın. Menüden **Uygulamayı yükle** veya **Ana ekrana ekle** seçin.

## Güncellemeler
